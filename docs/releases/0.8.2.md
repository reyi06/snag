# Snag 0.8.2

Snag 0.8.2 repairs public Instagram downloads.

## Highlights

- **Instagram reels and video posts** now resolve through yt-dlp instead of the retired captioned embed.
- **Instagram photo carousels** are exported as individual photos. Image-only entries use yt-dlp's best thumbnail URL.
- **Daily yt-dlp refresh** - Snag checks the stable yt-dlp release at most once per day. The bundled binary remains the fallback when the update cannot be downloaded.
- **Clear Instagram errors** - private posts, rate limits, audience-restricted posts, and removed posts produce specific guidance instead of a generic "No media found".

## Install

1. Download `Snag-0.8.2.apk`.
2. Allow installs from unknown sources for your browser or file manager.
3. Install on Android 10 or newer. This release is built for 64-bit ARM (`arm64-v8a`) devices.
4. For Scroll mode, open **Settings → Scroll mode**, enable it, and allow **Display over other apps**.

## What changed under the hood

- `InstagramYtDlpStrategy` requests `--dump-single-json` with `--ignore-no-formats-error`, parses carousel entries, prefers progressive video formats with audio, and uses the best thumbnail for image entries.
- The existing embed and OpenGraph strategies remain fallbacks.
- The yt-dlp refresh timestamp is stored in app-private preferences and does not retry in a loop.

## Verified

- Public Instagram reel resolves and saves an MP4.
- Public Instagram photo carousel resolves as five photos and saves five JPG files.
- Audience-restricted Instagram reel fails gracefully with retry guidance.
- YouTube video and playlist downloads continue to use the shared queue.
