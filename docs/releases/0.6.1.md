# Snag 0.6.1

Snag 0.6.1 makes public TikTok profiles resilient to transient `503` responses from the creator and post embeds.

## Highlights

- **Identity cache** — the stable `secUid` and profile metadata are cached per handle. Later opens can call TikTok's creator item-list API immediately instead of repeating the fragile embed lookup.
- **Stronger retries** — creator embeds use exponential backoff, post embeds try several recent posts, and the creator API gets a fresh scan after a short delay.
- **Honest partial profiles** — if the full profile still cannot be fetched, Snag marks it as partial, keeps the known full video count when available, and shows a **Recent posts only** banner.
- **Retry full profile** — partial profiles expose a retry action that runs the full path again instead of returning the same recent-only result.

## Install

1. Download `Snag-0.6.1.apk`.
2. Allow installs from unknown sources for your browser or file manager.
3. Install on Android 10 or newer.
4. For Scroll mode, open **Settings → Scroll mode**, enable it, and allow **Display over other apps**.
