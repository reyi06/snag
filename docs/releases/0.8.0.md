# Snag 0.8.0

Snag 0.8.0 adds YouTube downloads through an embedded yt-dlp runtime and multi-link batch input, while keeping the shared queue, history, progress, and file manager.

## Highlights

- **YouTube video** — download progressive video formats.
- **YouTube audio** — save the best audio-only stream.
- **YouTube playlists** — playlist links open in the same batch sheet as profiles. Up to 20 entries are resolved per playlist load.
- **Instagram** — reels, video posts, photos, and carousel images use the existing Instagram extractor.
- **Multi-link batch** — paste multiple supported links and resolve them into one batch sheet.
- **Shared pipeline** — YouTube, Instagram, TikTok, and Facebook all feed the existing WorkManager queue, history, MediaStore downloads, and progress notifications.

## Important

The APK now bundles the `youtubedl-android` runtime, including yt-dlp, Python, and FFmpeg. This makes the APK larger and the first YouTube request slower while the runtime initializes. Snag is licensed under **GPL-3.0** to comply with the bundled runtime.

## Install

1. Download `Snag-0.8.0.apk`.
2. Allow installs from unknown sources for your browser or file manager.
3. Install on Android 10 or newer.
4. For Scroll mode, open **Settings → Scroll mode**, enable it, and allow **Display over other apps**.

## Play Protect and legal

Snag is a sideloaded APK, so Android or Google Play Protect may warn about installing from an unknown source. Verify the SHA-256 checksum below and install only if you trust the source.
