# Snag 0.8.3

Snag 0.8.3 restores high-quality YouTube downloads and hardens Instagram reel extraction.

## Highlights

- **High-resolution YouTube** - adaptive video and audio streams are downloaded as a pair and merged with the bundled FFmpeg. Videos that offer 1080p, 1440p, or 2160p now save at that resolution instead of falling back to a low progressive stream.
- **Better Instagram reels** - reels that expose separate DASH video and audio streams are paired and merged into one MP4.
- **Stale extractor retry** - if Instagram reports a login wall, rate limit, or missing formats, Snag refreshes yt-dlp once and retries before showing an error.
- **Clear merge status** - the in-app bar shows `Downloading video + audio` and then `Merging video + audio` while the pair is processed.

## Install

1. Download `Snag-0.8.3.apk`.
2. Allow installs from unknown sources for your browser or file manager.
3. Install on Android 10 or newer. This release is built for 64-bit ARM (`arm64-v8a`) devices.
4. For Scroll mode, open **Settings → Scroll mode**, enable it, and allow **Display over other apps**.

## What changed under the hood

- YouTube variants now retain adaptive format IDs. A video-only format is stored with a yt-dlp selector such as `401+140`, pairing it with the best audio stream.
- `DownloadWorker` recognizes those jobs, downloads with yt-dlp into app cache, merges with FFmpeg, then copies the merged file into `Downloads/Snag` through MediaStore.
- Instagram reel extraction uses the same pairing approach when no progressive stream exists.
- Instagram applies a short retry/refresh path for stale yt-dlp binaries.
- High-resolution files are larger. A 2160p download can be several hundred megabytes; a Wi-Fi connection is recommended.

## Verified

- A 4K YouTube source saved as a 3840×2160 VP9 video with AAC audio.
- Public Instagram reel resolves and saves an MP4.
- Instagram photo carousel still resolves and saves all five JPG files.
- Audience-restricted Instagram posts continue to fail with retry guidance.
