# Snag 0.8.1

Snag 0.8.1 focuses on visible progress, faster YouTube playlists, and clearer recovery when a platform refuses a request.

## Highlights

- **In-app download bar** - a compact bar above the navigation bar shows the current file, batch position, percentage, transferred size, total size, and live transfer speed while downloads run. It follows you across the Save, Library, and Settings tabs.
- **Cancel long resolutions** - a loading card now shows what Snag is doing and provides **Cancel**. Cancelling restores the previous result instead of leaving the screen stuck.
- **Faster YouTube playlists** - playlist links resolve the first 10 entries with up to three concurrent yt-dlp lookups.
- **YouTube metadata cache** - resolved video metadata is kept in memory for 10 minutes, so repeat actions and retries avoid a second lookup.
- **Clearer Instagram failures** - rate limits, login walls, and removed posts now show specific retry guidance instead of the generic "No media found" message.
- **Smaller APK** - the published phone build is `arm64-v8a`, reducing the download from roughly 245 MB to roughly 100 MB.

## Install

1. Download `Snag-0.8.1.apk`.
2. Allow installs from unknown sources for your browser or file manager.
3. Install on Android 10 or newer. This release is built for 64-bit ARM (`arm64-v8a`) devices, which covers most Android phones.
4. For Scroll mode, open **Settings → Scroll mode**, enable it, and allow **Display over other apps**.

## What changed under the hood

- YouTube playlist resolution is capped at the first 10 entries for predictable load time. Pagination beyond the first page remains deferred.
- The download worker reports overall queue progress plus per-file bytes and a smoothed transfer speed through WorkManager.
- The in-app bar disappears when the queue empties and refreshes history once, so completed downloads appear without switching tabs.
- Long-resolution cancellation is scoped to the resolve job. The previous media or profile result returns unchanged.

## Verified

- YouTube video resolution and MP4 save.
- YouTube playlist resolution, batch sheet, and a 10-file queue download.
- In-app progress bar with file count, percentage, size, and MB/s speed.
- Cancel action on a playlist resolution.
- Signed release APK installs over the previous Snag release.
