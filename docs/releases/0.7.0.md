# Snag 0.7.0

Snag 0.7.0 adds a low-profile floating button, opacity control, and quieter save feedback.

## Highlights

- **Low-profile button** — choose a smaller black button with a white crown instead of the default maroon/gold crown.
- **Opacity control** — set the floating button between 35% and 100% opacity.
- **Live updates** — changing the style or opacity rebuilds the button immediately.
- **Button animation** — a spinner while Snag reads the copied link, a green pulse on success, and a red shake on error. Successful saves no longer show a toast.
- **Realme/ColorOS fallback** — if Display over other apps is denied, Scroll mode keeps its notification active. Use the notification's **Save copied link** action.

## Install

1. Download `Snag-0.7.0.apk`.
2. Allow installs from unknown sources for your browser or file manager.
3. Install on Android 10 or newer.
4. For Scroll mode, open **Settings → Scroll mode**, enable it, and allow **Display over other apps**.
