# Snag 0.6.0

Snag 0.6.0 adds a floating save button for TikTok and keeps the no-login profile flow from 0.5.x.

## Highlights

- **Scroll mode** — a draggable maroon-and-gold crown stays on screen. Copy a TikTok video link, tap the crown, and Snag reads the clipboard, resolves the post, and downloads it in the background.
- **Manual by design** — no automatic scrolling, no Accessibility service, and no share-sheet automation. The clipboard is read only after an explicit crown or notification action.
- **Notification controls** — the persistent Scroll mode notification offers **Save copied link** and **Stop**. Stopping immediately clears the Settings switch.
- **No-key TikTok profiles** — public profiles resolve through TikTok's creator embed and creator item-list API, without cookies, a login, or a third-party key.
- **Download progress** — foreground notifications show `Downloading 1/32`, a determinate bar, and a live percentage.
- **Large batches** — long TikTok CDN URLs no longer hit WorkManager's 10 KB data limit.
- **Carousel thumbnails** — each saved slide uses its own image URL, and completed slides prefer the saved local file.

## Install

1. Download `Snag-0.6.0.apk`.
2. Allow installs from unknown sources for your browser or file manager.
3. Install on Android 10 or newer.
4. For Scroll mode, open **Settings → Scroll mode**, enable it, and allow **Display over other apps**.
